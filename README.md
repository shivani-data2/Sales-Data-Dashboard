# 📊 Sales Data Dashboard

## 📌 Project Overview
This project is an interactive Sales Data Dashboard developed using **Microsoft Power BI**. It provides insights into sales performance, profit, and business trends through interactive visualizations.

---

## 🚀 Features

- 📈 Sales KPI Cards
- 💰 Profit Analysis
- 🌍 Region-wise Sales Analysis
- 📅 Monthly Sales Trends
- 📊 Interactive Charts & Graphs
- 🎯 Slicers and Filters
- ⚡ DAX Measures
- 🔄 Data Cleaning using Power Query

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
